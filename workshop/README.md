# Workshop-Materialien

Slides und (perspektivisch) Handouts für den **KI-Workshop Mai 2026**, der dieses
practice-repo als Übungs-Codebase nutzt.

## Slides

| Datei | Block | Inhalt |
|-------|-------|--------|
| `presentations/01-vom-entwickler-zum-orchestrator.html` | Block 1 | Mindset-Shift, Reifegrad-Modell, Live-Demo |
| `presentations/02-uebungen.html` | Block 2 + 5–7 | Übungs-Slides für alle Hands-on-Blöcke (inkl. der drei `/prime-*`-Runden in Block 5 und der Pipeline-Stufen ①–⑥ in Block 6/7) |
| `presentations/block4-ai-patterns.md` | Block 4 | 5 AI-Interaction-Patterns (HITL, Reusable Commands, Subagents, Parallel, No-AI) |

Alle HTML-Slides sind self-contained — einfach im Browser öffnen. Markdown-Slides
können mit jedem Markdown-Renderer / Slidedeck-Tool gerendert werden.

## Reference-Commands

Die in den Slides referenzierten OpenCode Custom Commands (`/prime-*`,
`/context`, `/plan`, `/test-plan`, `/implement`, `/review`, `/retro`, optional
`/pipeline`) liegen in [`../.opencode/commands/`](../.opencode/commands/README.md).

## Anpassen für eigenes Team

Die Slides sind generisch gehalten — Beispiele aus dem Pharma-Engineering-Umfeld
(Begriffe wie *Charge*, *Rezept*, *Anlage*, GMP) sind als Branchenbeispiele drin
und können für andere Industrien einfach ausgetauscht werden. Die didaktische
Struktur (Stufenmodell, Pattern-Gallery, 5-Stufen-Pipeline + Retro) bleibt
gleich.
